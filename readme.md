Como escrever um novo post
Duplique o arquivo posts/vieses-planejamento-financeiro.html.
Renomeie o arquivo (ex: posts/reserva-de-emergencia.html).
Troque o título, a data e o conteúdo dentro das tags <h1>, <p class="post-meta"> e dos parágrafos.
No index.html, copie o bloco <div class="entry">...</div> do lançamento 001, cole acima dele, e atualize:
o número do lançamento (002, 003...)
o link (href="posts/seu-novo-arquivo.html")
o título e o resumo
Suba (git push) — o GitHub Pages atualiza sozinho em cerca de um minuto.
